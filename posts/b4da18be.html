十八、常见现象排查

1. 首页只显示几篇

现象：导入老文章后，首页只看到最近 3 篇。

原因：Hexo 按日期倒序排，老文章排到后面了。

验证：

解决：翻页，或把老文章日期改成近期。

2. CSS 改了没生效

现象：改了 custom.css，页面上没变化。

原因：浏览器或 Cloudflare 缓存了旧版本。

解决：

  1. _config.butterfly.yml 里 ?v= 后的数字加 1
  2. hexo clean && hexo d -g
  3. Ctrl + Shift + R 强刷

3. URL 太长（中文编码）

现象：/2023/06/02/suishen_wifi_md/%E6%96%B0%E7%89%88...

解决：装 hexo-abbrlink 插件，见第十二章。

4. 图片加载慢

现象：背景图半天不出来。

解决：见第十四章，压缩图片 + 开懒加载。

5. 部署时 10+ 文件变化

现象：每次 hexo d 都提交一堆文件。

原因：

  • 文章缺 date 或 updated
  • CRLF 换行符转换

解决：

6. favicon 404

现象：控制台报 GET /favicon.ico 404。

原因：source/img/favicon.ico 不存在。

解决：放一个图标，或忽略（不影响功能）。

7. 字体 404

现象：/font/UnidreamLED.ttf 404。

解决：

  • 下载字体放到 source/font/，或
  • 删掉 custom.css 里的 @font-face 段

8. 头像转圈

现象：侧边栏头像一直转圈。

原因：source/img/avatar.jpg 不存在。

解决：放一张头像，或把配置注释掉。

9. 文章卡片 404 图

现象：首页文章封面显示 404。

原因：文章 front-matter 里的 cover: 路径图片不存在。

解决：

  • 删掉该行让它用 default_cover，或
  • 放对应图片到 source/img/

10. 导航/标题在深色背景上看不清

现象：文字太暗，和背景糊在一起。

原因：custom.css 里明亮模式文字颜色是深灰 #2c3e50。

解决：改成白色 #ffffff 加阴影，见第八章第 2 节。

十九、踩坑记录

坑 现象 解决
Steam++ 改 hosts ping github.com 返回 127.0.0.1，SSH Connection refused 打开 Steam++ → 取消 GitHub 相关项；或手动清 hosts 里 # Steam++ Start 到 # Steam++ End 之间内容
SSH 22 端口被封 ssh -T git@github.com 报 Connection refused ~/.ssh/config 走 ssh.github.com:443
公钥没加 GitHub Permission denied (publickey) cat ~/.ssh/id_ed25519.pub 复制到 GitHub SSH keys
部署走 HTTPS unable to access 'https://...' _config.yml 的 repo 改成 git@github.com:...，rm -rf .deploy_git
YAML 重复键 YAMLException: duplicated mapping key 搜重复的键（如 local_search:）删掉一个
运行时间 NaN 显示 NaN 年 NaN 天 new Date(2026, 9, 4, 19, 5, 28) 用数字参数
自定义域名 404 域名访问 404 检查 source/CNAME、Pages 的 Custom domain、DNS 记录
改名后部署失败 旧地址指向不存在仓库 _config.yml 改 deploy.repo 和 url，rm -rf .deploy_git
每次部署 11 个文件变化 列表页抖动 文章加 date 和 updated；_config.yml 加 updated_option: 'date'、index_generator.order_by: -date
CRLF 警告刷屏 大量 LF will be replaced by CRLF 加 .gitattributes，git config --global core.autocrlf false
message 显示 YYYY-10-2026年... now() 不工作 message 改成固定文字 "更新博客"
CSS 改了没生效 页面无变化 ?v=1 加 1；hexo clean && hexo d -g
头像转圈不显示 吃豆人动画 source/img/avatar.jpg 不存在
文章 404 封面 卡片显示 404 图 删掉 cover: 行或补图片
夜间卡片磨砂重 背景透太多 rgba(30, 30, 30, 0.6) 改成 0.9
导入文章首页看不到 老文章排到后面 翻页，或改日期到近期

访客统计一直转圈 busuanzi 不稳定 换 https://events.vercount.one/js
?v=2 报 404 CSS 完全不生效 改成 ?v=10，清 Cloudflare 缓存
custom.css 404 页面样式全丢 检查 public/css/custom.css 是否生成，Cloudflare 清缓存
